math

#01
Librería Estándar de Python
Nativa

Operaciones numéricas de alta precisión, constantes científicas (π, e, τ), geometría euclidiana, combinatoria y validaciones seguras de punto flotante con isclose().

math.gcd / lcm comb & perm math.dist isclose
01_math_example.py 
import math

# MCD, MCM y combinatoria
a, b = 48, 180
mcd = math.gcd(a, b)  # 12
mcm = math.lcm(a, b)  # 720
formas = math.comb(10, 3)  # 120 combinaciones

# Distancia euclidiana 3D & flotantes
dist = math.dist((1.0, 2.0, 5.0), (4.0, 6.0, 5.0))
es_igual = math.isclose(0.1 + 0.2, 0.3)  # True seguro

Externa

Generación rápida y vectorial de archivos PDF. Soporta configuración de fuentes tipográficas, celdas de alineación, encabezados, autores y exportación directa a archivo .pdf.

FPDF() add_page & set_font cell / multi_cell output(.pdf)
05_fpdf_example.py 
from fpdf import FPDF

pdf = FPDF()
pdf.add_page()

# Título con Helvetica negrita
pdf.set_font("Helvetica", "B", 18)
pdf.cell(0, 15, "Reporte Académico Unidad 2", new_x="LMARGIN", new_y="NEXT", align="C")

# Cuerpo de texto justificado y guardado
pdf.set_font("Helvetica", size=11)
pdf.multi_cell(0, 8, "Documento generado con FPDF2.")
pdf.output("mi_documento_fpdf.pdf")

Requests

#10
pip install requests
Externa

Cliente HTTP elegante para interactuar con APIs REST. Peticiones GET y POST con serialización JSON, headers personalizados, timeouts y control de fallos con raise_for_status().

GET / POST REST raise_for_status() JSON parsing Timeouts seguros
10_requests_example.py 
import requests

url = "https://jsonplaceholder.typicode.com/posts"
params = {"userId": 1}

# GET con timeout y control de excepciones
res = requests.get(url, params=params, timeout=10)
res.raise_for_status()  # Error si 4xx o 5xx

posts = res.json()
print(f"Obtenidos {len(posts)} posts del servidor.")

Instalación y Configuración del Entorno

Guía interactiva para aislar el entorno en Windows (PowerShell/CMD) o macOS/Linux

Python 3.9+ recomendado
Pasos para PowerShell: crear venv, habilitar ejecución si aplica e instalar dependencias. 
# 1. Navegar a la carpeta
cd python-librerias-ejemplos

# 2. Crear entorno virtual aislado
python -m venv venv

# 3. Activar en PowerShell
.\venv\Scripts\Activate.ps1

# 4. Instalar librerías externas
pip install -r requirements.txt
Pasos para el símbolo del sistema clásico (CMD en Windows). 
:: 1. Entrar al directorio
cd python-librerias-ejemplos

:: 2. Crear entorno virtual
python -m venv venv

:: 3. Activar en CMD
venv\Scripts\activate.bat

:: 4. Instalar dependencias
pip install -r requirements.txt
Pasos para sistemas basados en Unix (macOS / Linux / WSL). 
# 1. Navegar a la carpeta
cd python-librerias-ejemplos

# 2. Crear venv con python3
python3 -m venv venv

# 3. Activar entorno
source venv/bin/activate

# 4. Instalar dependencias
pip install -r requirements.txt
💡 Integración con Visual Studio Code: Abre el proyecto ejecutando code . y presiona F5 o el botón "Run Python File" en cualquier script.
